# 🎟️ Ingressos - Sistema de Venda de Ingressos

Este é um projeto de interface responsiva para venda de ingressos de shows, desenvolvido utilizando **HTML5**, **CSS3** e o framework **Bootstrap 5**.

---

## 🚀 Funcionalidades

O projeto está dividido em três áreas principais integradas através do sistema de Grid do Bootstrap:

1. **Barra de Navegação (Navbar)**
2. **Cadastro do Comprador (Área 1):**
   - Formulário interativo.
   - Campos para Nome Completo, E-mail, CPF e Data de Nascimento.
   - Area para upload de foto (destinado à confecção do crachá do evento).
   - Menu de seleção para escolha do setor do show.
   - **Seção de Brinde Exclusivo**
3. **Carrossel de Setores (Área 2):**
   - Um componente `carousel` centralizado.
   - Exibe cards personalizados com os preços e os resumos de vantagens de cada setor
4. **Termos e Condições (Área 3):**
   - Um componente utilizando accordion.
   - Apresenta de forma organizada avisos importantes sobre classificação indicativa e retirada de brindes.

---
